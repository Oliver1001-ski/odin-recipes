# odin-recipes

This is a simple recipe website built as part of **The Odin Project** curriculum. The goal of this project is to practice creating a basic multi-page website using structural HTML.

## Included Recipes
Here are the recipes featured on this website:
*   [Carbonara](./carbonara.html) - A classic Italian pasta dish.
*   [Fried Chicken](./fried-chicken.html) - Crispy, golden southern-style chicken.

## Skills Learned
*   Creating a structured HTML directory.
*   Linking local pages together using relative paths (`<a>` tags).
*   Using lists (`<ul>`, `<ol>`), headings, and images in HTML.
*   Managing files and committing code via Git.
